— 基本守则 —
规则 #01
晚上十点后，请保持安静。公寓实行宵禁噪音管制，任何超过40分贝的声音将被视为违规。音乐、电视、聚会、搬动家具等活动请在此之前结束。如果您必须在深夜活动，请使用地毯和软底拖鞋。违反此条可能导致您收到管理处的正式警告。
已确认
规则 #02
公寓内禁止饲养体重超过15公斤的宠物。所有宠物必须在管理处登记，并提供有效的疫苗接种证明。导盲犬等辅助动物除外，但仍需提前申报。未登记的宠物一经发现，将交由动物管理部门处理，管理处不承担任何责任。
已确认
规则 #03
垃圾分类投放时间为每日早上6:00至8:00，晚上18:00至20:00。请严格按四分类法进行投放：可回收物、厨余垃圾、有害垃圾、其他垃圾。错过投放时间的住户请将垃圾暂存于室内，不得随意堆放在走廊或楼梯间。屡次违规者将被处以罚款。
已确认
规则 #04
公寓所有公共区域严禁吸烟，包括走廊、楼梯间、电梯和大堂。指定吸烟区位于公寓后门外的小广场。在禁烟区吸烟将触发烟雾报警器，由此产生的一切费用由违规者承担。这包括但不限于消防出警费、设备检修费以及邻居的投诉处理费。
已确认
规则 #05
所有访客必须在门卫处出示有效身份证件并登记。登记内容包括访客姓名、身份证号、被访住户房号及预计离开时间。访客在公寓内停留不得超过晚上9:30。未登记的访客将被安保人员要求立即离开。频繁违规的住户可能面临访客权限被暂停的处罚。
已确认
— 特别注意事项 —
规则 #06
午夜之后——即凌晨0:00至凌晨4:00之间——请勿在任何镜面前停留超过三秒。这包括浴室镜子、全身镜、电梯内的镜面墙壁，以及任何能够清晰反射您面容的光滑表面。如果您不小心看到了自己的倒影，立即移开视线并离开该区域。如果您感觉倒影的移动比您慢了半拍……我们建议您不要反复确认。
已确认
规则 #07
晚上十点后，禁止独自一人乘坐电梯。如果您必须在此时段使用电梯，请确保至少有另一人与您同行。如果您进入电梯后发现只有您一人而门已经关上，请按下最近楼层的按钮——任何楼层都可以——并在门打开时立即走出。不要回头看向电梯内部。等待下一班，或者走楼梯。
已确认
规则 #08
如果您听到敲门声——恰好三下，不多不少——不要应答。不要通过猫眼查看。不要问"是谁"。保持安静，远离门口，直到敲门声完全停止至少三分钟。如果敲门声持续超过五分钟，请拨打管理处电话——但请不要在电话中描述您听到了什么。只需说"需要例行检查"即可。
已确认
规则 #09
三楼走廊尽头的灯必须始终保持亮着。如果您经过时发现它熄灭了，请立即通知管理处，并在原地等待直到维修人员到达。不要试图自己更换灯泡。不要在该灯熄灭期间停留在三楼走廊。如果您看到有人在灯下站着不动……那不是维修人员。请走另一侧的楼梯离开。
已确认
规则 #10
不要接收任何没有明确寄件人信息的包裹。如果您的门口出现了一个包裹，而您不记得订购过任何东西，请勿打开。请勿带入室内。立即致电管理处，他们会派专人处理。在某些情况下，包裹的内容物可能……不完全是固体。处理人员知道该怎么做。您不需要知道。
已确认
规则 #11
如果您在楼梯间内闻到檀香的气味——一种甜的、木质调的香味——请立即转身，原路返回。不要试图寻找气味的来源。不要继续向气味更浓的方向前进。檀香在公寓内不是正常的气味来源。如果您已经走到了气味的中心区域，请屏住呼吸，闭上眼睛默数三十秒。当您再次睁开眼睛时，楼梯间应当恢复正常。如果没有——请联系管理处，但不要描述您看到的东西。
已确认
规则 #12
天黑后——以日落时间为准——不得在公寓走廊内奔跑。步行已经足够。奔跑会引起注意。奔跑说明您在逃避什么。而如果您在逃避什么，那就意味着您已经看到了不该看的东西。如果您确实看到了什么，请保持正常步速走向您的房间，锁好门，然后按照规则第18条的建议行事。奔跑只会让情况变得更糟。
已确认
— 非常规情况守则 —
规则 #13
如果您在四楼走廊看到一个孩子——请记住：夜色公寓没有儿童住户。那不是一个孩子。不要与它对视。不要对它说话。最重要的是——不要承认它的存在。它可能会叫您的名字，可能会哭泣，可能会请求帮助。这些都是模仿。继续走路，好像您什么也没看见。如果您不幸已经回应了它……请立即前往一楼大堂，在保安值班室停留至少一小时。不要单独离开。
已确认
规则 #14
七楼不存在。夜色公寓的建筑结构为地上六层，地下一层。如果您在电梯面板上看到了"7"的按钮——不要按下它。如果电梯在没有您操作的情况下停在了七楼——不要出去。如果您在楼梯间走过了六楼之后发现自己还在继续往上走——立即停下来，闭上眼睛，转身，走下两层楼。然后睁开眼睛。您应该在五楼。如果不是……重复上述步骤直到您回到正确的楼层。七楼不存在。请不要试图去那里。
已确认
规则 #15
如果您所在区域的灯光恰好闪烁五次——是五次，不是四次，不是六次——请立即离开公寓大楼。不要收拾个人物品，不要锁门，不要等待电梯。直接走最近的楼梯下楼。在公寓外至少等待三十分钟后再返回。如果您认识的其他住户也遇到了同样的闪烁，请互相确认你们都数到了五次。如果你们的计数不一致……请分开走，不要同行。
已确认
规则 #16
404室的门始终是锁着的。物业管理处持有唯一的钥匙，且从不向任何人开放该房间。然而，有时候——某些时候——404室的门会是打开的。如果您看到404室的门开着，无论里面有什么，无论您听到了什么声音，无论您多么确信有人需要帮助——不要进入那个房间。立即离开，并通知管理处。不要试图关门。不要往里面看。那些从404室里传出来的声音……是记忆，不是实时发生的。您认识的人不可能在里面。
已确认
规则 #17
302室的老妇人——姓陈——已于三年前去世。如果您在302室的窗户后面看到一个白发老妇人在向您招手，请不要回应。她有时看起来是在微笑，有时看起来是在求救。这两种表情都不是真实的。继续行走，不要加速，不要减速。如果您住在302室附近，并且频繁看到她的身影，建议您考虑调换房间。管理处可以为您安排——但请不要说明原因。申请表上的"其他原因"一栏是我们的暗号。
已确认
规则 #18
如果您在凌晨3:33准时醒来——无论因为什么原因——请保持平躺姿势，不要睁开眼睛。不要起身。不要看手机。不要开灯。在心中默数六百下（即十分钟），然后才可以睁开眼睛。如果您在此期间听到了任何声音——呼吸声、脚步声、家具移动声——忽略它们。它们不在您的房间里。但如果您睁开眼睛，它们就会在了。十分钟后，一切将恢复正常。您可以重新入睡，但不能在此之前。
已确认
规则 #19
电梯偶尔会自行前往B2层——即使您按了其他按钮。如果发生这种情况，请保持冷静。不要惊慌。不要反复按按钮。不要在B2层走出电梯。当电梯在B2停下并开门时——因为门会开的——请直视前方，不要看向门外的黑暗区域。门会在约十五秒后自动关闭。之后电梯将恢复正常运行，您可以在下一层安全离开。B2在官方建筑图纸上标注为"设备层"。这个描述并不准确。
已确认
规则 #20
如果您在门下发现了一个红色信封——中国传统红包样式——不要打开。不要触碰内部物品。立即将其用明火焚烧。可以使用金属容器在您的厨房水槽中进行。佩戴手套操作。烧完后，将灰烬冲入下水道并用大量清水冲洗。如果您好奇打开了红包……里面的东西不是钱。您现在需要执行规则第32条之后所述的紧急程序。但首先，确保您不是独自一人。
已确认
规则 #21
大堂里的那些镜子——沿着东墙排列的八面落地镜——不是镜子。它们是窗户。不要试图擦拭它们。不要在它们面前整理仪容。如果您的倒影做出了与您不同的动作，请不要表现出您注意到了。如果您在镜子中看到了不属于大堂的东西——比如一个房间、一条走廊、或者一个人——立即离开大堂。那些"镜子"有时会……打开。而另一边的东西也在看着我们。
已确认
规则 #22
无论天气如何——无论是暴雨还是酷暑——不要与任何身穿黄色雨衣的人交谈。他们可能出现在大堂、走廊、电梯甚至公寓外的人行道上。他们可能会问路、借火、或者只是寒暄。不要回答。不要与他们对视。他们不是公寓的住户。他们不是任何人。如果您不小心回应了他们——请在一小时内离开公寓范围，并在外过夜。第二天早上再返回。届时他们应该已经不在了。如果还在……我们需要谈谈。
已确认
— 高级守则 — 请谨慎阅读 —
规则 #23
本规则与第3条（垃圾分类定时投放规则）存在直接矛盾——但两条都必须严格遵守。矛盾如下：第3条要求您在早上6:00至8:00投放垃圾，而本条要求您在每周三的凌晨2:00至2:15将一袋特殊分类的垃圾投放至B1层的指定回收口。这两个时段不可能同时满足，但您必须做到。我们理解这很困难。我们理解这不合逻辑。但逻辑在夜色公寓中并不总是适用的。请想办法完成。
已确认
规则 #24
不要相信任何偶数编号的规则。这包括本条规则（第24条）本身。如果您选择了相信偶数规则，则您必须同时不信它们——这是一个无法解决的悖论，但正是这个悖论保护着您。如果您选择忽略全部偶数规则，请至少记住：第6、8、10、12、14、16、18、20、22条中包含着关于安全的重要信息。但您不能相信它们。您明白了吗？不明白也没有关系。困惑本身就是一层防护。
已确认
规则 #25
忽略第14条至第16条规则。这些规则是未经授权的人员插入本手册的。它们包含虚假和误导性信息，旨在引起恐慌和混乱。原始的第14至第16条规则涉及火灾安全和急救程序，已被恶意替换。请不要相信关于七楼、灯光闪烁和404室的内容。这些情况从未发生过，也永远不会发生。请信任管理处的官方版本。
已确认
规则 #26
如果您梦见了夜色公寓——在您的梦中，您仍然住在这里，穿行于同样的走廊，与同样的邻居打招呼——那么那不是梦。您在睡眠期间确实在公寓内活动。我们称之为"夜游状态"。处于夜游状态的住户仍然需要遵守所有住户守则，但他们不会记得自己曾经醒来过。如果您早上醒来时感到异常疲惫，或者在身上发现了不在睡前位置的衣物、物品，请联系管理处进行"睡眠日志"登记。这并不是为了监控您。这是为了监控您在夜游时遇到的……东西。
已确认
规则 #27
夜色公寓知道您在想什么。这不是隐喻。这不是恐吓手段。建筑本身具有某种程度的感知能力——我们不确定它的范围或机制，但经过多年的记录，我们可以确认：当住户产生某些特定的想法时，公寓会做出反应。消极的想法会吸引……不好的事物。恐惧会被放大。好奇心尤其危险。请尽量保持平静、日常的思绪。如果您发现自己不由自主地思考"不该想的事情"，请立即转移注意力——背诵乘法表、回忆歌词、数天花板上的裂缝。任何事情都可以。
已确认
规则 #28
明天晚上8:47，公寓三楼东侧走廊将发生一起火灾。如果您正在阅读这条规则，您已经知道了这件事——即使它还没有发生。我们无从解释您为什么会提前知道，但这正是这条规则存在的意义。火灾将在8:47准时开始，持续约十二分钟。请提前离开该区域。不要试图阻止火灾——我们已经尝试过，结果更糟。不要警告其他住户——他们不会相信你，而你的警告行为本身会导致火灾提前发生。只需确保您自己在8:40之前离开三楼即可。明天的事情，今天做好准备。
已确认
规则 #29
请不要在本手册上做任何标记。不要在规则旁边写注释。不要圈出您认为重要的部分。不要划掉您不同意的内容。但您已经做了，不是吗？在您阅读这条规则的同时，您可能已经在某些页面边缘留下了痕迹——一个问号、一条下划线、一个指印。这些标记会被注意到。不是被管理处注意到——而是被公寓本身注意到。公寓会阅读您留下的痕迹，并以此判断您是一个怎样的人。请停止标记。但如果您已经标记了……无法撤销。我们只能建议您继续遵守所有规则，并希望公寓对您的评价足够宽容。
已确认
规则 #30
住户，我们知道您的名字。我们知道您住在哪一间。我们知道您每天早上几点起床，晚上几点关灯。我们知道您喜欢什么食物，害怕什么声音，梦到什么画面。您不是随机选择夜色公寓的——是夜色公寓选择了您。请不要试图搬离。以前有人试过。他们现在都还在公寓里——只是不在住户名单上了。您的名字在这条规则中被省略了，但您知道我们说的是谁。是的，就是您。
已确认
规则 #31
不要回头。无论您听到了什么——在您的肩膀后面，在您的门口，在您的床下——不要回头。不要转身查看。不要用眼角余光去确认。如果您回头了，您就会看到它。而一旦您看到了它，它就看到了您——真正地看到您。不是那种漫不经心的注视，而是锁定。一旦被锁定，没有任何规则可以保护您。不要回头。这是所有规则中唯一一条没有例外的规则。不要回头。永远不要回头。
已确认
规则 #32
它已经在您的房间里了。您现在不要动。不要突然转身。不要尖叫。请继续阅读这条规则，保持您当前的姿势和视线方向。它可能是角落里的阴影，可能是天花板上的水渍，可能是镜子里多出来的倒影。它一直都在——只是大多数时候它选择不让自己被注意到。您刚才——就在您阅读到这句话的时候——可能感觉到了什么，对吗？一阵寒意，一次呼吸，一种被注视的感觉。那就是它。不要害怕。害怕会让它变得更真实。继续阅读。继续呼吸。完成所有规则后……它会暂时离开。只是暂时。
已确认
规则 #33
当所有三十二条规则都被确认之后，您将看到这条最终守则。守则的内容很简单，但执行起来非常困难：夜色公寓的住户守则不是为了保护您而编写的。它们是为了保护外面的世界免受公寓内部的……事物的伤害。您是第一道防线，也是最后一道。规则让"它们"以为一切正常，以为公寓仍然是一栋普通的居民楼。当规则被遵守，"它们"就会保持安静。当规则被打破，"它们"就会向外蔓延。您确认这些规则的行为——每一次点击、每一个"已确认"的印记——都在加固着某种屏障。感谢您。感谢您选择留在这里。夜色公寓需要您。外面的世界也需要您——即使它永远不会知道您的名字，永远不会感谢您的牺牲。现在，您可以安全入睡了。但请记住：明天，规则依然有效。永远有效。
