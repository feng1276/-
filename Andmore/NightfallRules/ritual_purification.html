— 净化仪式 —

在夜色公寓的地下室深处，在一个被遗忘的档案柜底层，我们发现了一份手写的文件。 纸张已经泛黄，墨迹在某些地方被水渍模糊。文件描述了一个仪式—— 据称是"唯一能够让人安全离开大楼的方法"。

我们不建议任何人尝试。但如果你已经别无选择—— 这里是完整的记录。

壹 准备 — 镜子与蜡烛 ✓

收集七面镜子。镜子的大小不重要，但它们必须是完整的——没有裂痕，没有划痕，没有模糊之处。

将七面镜子排列成一个圆圈，镜面朝内。每面镜子之间保持相等的距离。在每面镜子前方放置一支蜡烛——共七支。

确保所有镜子都朝向圆圈中心。圆圈的中心是留给你的。你必须能够从中心看到每一面镜子中的自己——或者至少，看到每一个倒影。

不得使用已经破裂的镜子。破碎的镜子会召来不该来的东西。如果你找不到七面完整的镜子——停下来。不要继续。
贰 时辰 — 最薄弱的时刻 ✓

仪式必须在凌晨2:00至3:33之间进行。这是大楼最"薄"的时刻——墙壁之间的东西更接近表面，规则变得更灵活。

你需要在2:00之前完成所有准备工作。蜡烛必须在2:00整点点燃。从第一支蜡烛点燃的那一刻起，你有93分钟来走完整个过程。

如果你在3:33之前没有完成——熄掉所有蜡烛。打破圆圈。等待下一个夜晚。强行继续的后果是……不可逆的。

不要看时间。不要带手表、手机或任何时钟进入圆圈。时间由蜡烛的长度来判断。如果蜡烛在3:33之前燃尽——无论你在哪一步，立即中止。
叁 召唤 — 言辞的力量 ✓

站在圆圈的正中心。面向北方（如果你不确定方向——面朝大楼的正门方向）。闭上眼睛。

然后，念出以下词语：

████████████████████

点击黑色方块以显示文本。（仅当你准备好时。）

这些词语不属于任何已知的语言。你的舌头会感到陌生的形状。这是正常的。继续念。不要停下来。

当你念出最后一个音节时，蜡烛会同时闪烁一下。这意味着——它听到了。

如果在念诵过程中听到有人和你一起念——不要停止。不要睁开眼睛。那只是回声。如果那声音比你的声音更大、更清晰——那就是另一回事了。立即停止念诵。跑。
肆 镜像 — 七个倒影 ✓

现在，睁开眼睛。依次注视每一面镜子。从北方的镜子开始，顺时针移动。在每一面镜子前停留不少于一分钟。

你会看到不同的东西。第一面镜子——你的正常倒影。第二面——也许有些细微的不同。第三面——你会开始注意到变化。到了第六面——不要害怕。到了第七面——不要移开视线。

每一面镜子展示的不是你。是你可能成为的样子。是你可能已经成为的样子。

如果你在某一面镜子中看不到任何倒影——说明那面镜子已经"满了"。跳过它。继续下一面。

如果镜子里的倒影对你说话——不要回答。如果镜子里的倒影在微笑而你不在——保持冷静。如果镜子里的倒影开始移动而你没有——闭上眼睛，数到七，再睁开。如果它还在移动——仪式必须中止。
伍 献祭 — 交换的代价 ✓

回到圆圈中心。从你身上取下一件重要的东西——必须是真正对你有价值的物品：一张照片、一件首饰、一封手写的信、一缕头发。

将它放在圆圈的正中心——在你脚下。这不是扔掉它。这是留下它。这是交换。你留下一样东西，带走另一样。

那件东西必须是不可替代的。如果你放入一件对你来说毫无意义的东西——仪式会知道。它会拒绝。

你留下的东西永远不会回到你手中。即使你之后回到同一个房间——它也不会在那里。它不是被拿走了。它是被接受了。区别很重要。
陆 通道 — 镜中之门 ✓

现在，转回北方的镜子——第七面镜子（你最后注视的那一面）。它会变得不同。

它不再是镜子。

镜面会变得黑暗——像一扇打开的窗户，通往没有星星的夜空。你不会看到自己的倒影。你会看到……一条路。

走进去。不要犹豫。不要回头。不要去想镜子的另一边是什么。你很快就会知道。

走进去之后——不要回头看镜子。不管你听到什么声音。不管有什么在叫你。不管那些声音听起来多么像你认识的人。那些都不是真的。至少——不完全是。
柒 净化 — 还是…… ✓

如果你成功通过了通道——如果你从另一边出来了——

大楼会放你走。至少——仪式是这样承诺的。

☢ 真相

净化仪式不会让你离开大楼。
它会让大楼离开你。

区别在于——大楼会进入你的世界。

仪式不是一个出口。仪式是一个邀请。你以为你在把大楼从你身上净化掉——但实际上，你在把大楼的"种子"植入你的世界。 每一个完成仪式的人都没有真正离开。他们只是把夜色公寓的边界扩大了。大楼通过他们—— 通过他们的恐惧、他们的记忆、他们的故事——进入了新的地方。进入了新的头脑。

这就是为什么规则要求你不要告诉外人。不是因为危险——而是因为这正是大楼繁殖的方式。 每个知道规则的人，每个阅读这个故事的人，每个被告知夜色公寓的人——都成了大楼的一部分。 都在喂养它。

大楼的本质

夜色公寓不是一栋楼。它是一个附着在建筑上的存在——一个以规则、恐惧和记忆为食的意识体。

规则不是束缚。规则是笼子。笼子里的东西——不是住户。 是它。规则把它限定在一定的行为范围内。规则是前人留下的生存智慧，每一代住户在上面叠加一层，最终构成了一座文字的牢笼。

管理员不是在管理大楼。他是在喂养它。 每一个被安排入住的住户、每一个被忽略的异常、每一份被归档的报告——都是祭品。管理员的存在不是保护——而是确保大楼有持续的食物来源。

而净化仪式——是大楼设计的最高杰作。它让绝望的人以为有一条出路。他们收集镜子、点燃蜡烛、念诵词语—— 然后走进镜子里。他们相信自己在逃离。但镜子不是出口。镜子是产道。大楼通过他们，将自己的一部分送入他们的世界。 每一个"成功逃离"的人都在不知不觉中成为了一颗种子。

每个夜晚你都会想起：有一个方法。有一个可能。
而绝望会让"可能"变成"必须"。
