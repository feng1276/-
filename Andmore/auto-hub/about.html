🎯 项目简介

AutoHub 是一个高端汽车展示与对比平台，致力于为汽车爱好者和潜在购车者提供全面、专业的汽车资料。我们收录了来自全球各大品牌的车型数据，通过分类浏览、性能对比、排行榜和技术解析等多种方式，帮助用户深入了解每一款车型。平台采用纯原生技术栈构建，追求极致的性能与用户体验，以赛博科技风格呈现汽车数据之美。

✨ 功能特色

  • 车型大全——50+款车型（涵盖超级跑车、豪华SUV、电动先锋等）的详细参数和多维度介绍
  • 品牌中心——25+全球知名品牌的详细介绍、发展历程和代表车型
  • 专区浏览——SUV专区、跑车专区、电动车专区，按类别深度探索
  • 性能对比——参数对比表格 + Canvas可视化条形图，直观展示差异
  • 排行榜——最快加速、最高极速、最长续航、最贵车型等权威榜单
  • 车展新闻——瀑布流布局的最新汽车资讯，覆盖全球五大车展

🛠️ 技术实现

本项目使用纯原生HTML、CSS和JavaScript构建，未使用任何前端框架。技术要点：

  • CSS变量系统实现统一的赛博科技风主题配色
  • 深色/浅色模式切换（localStorage持久化，key: autohub-theme）
  • CSS Grid + Flexbox 响应式布局，自适应所有屏幕尺寸
  • JavaScript动态数据渲染和交互逻辑，模块化代码结构
  • IntersectionObserver实现滚动动画与懒加载
  • CSS动画实现霓虹发光、卡片悬浮、渐变边框等视觉效果
  • Canvas API 绘制性能对比图表和可视化数据展示
  • SVG 图形用于品牌 Logo 和界面装饰元素

⚙️ 技术栈详解

AutoHub 底层技术架构一览

📄

HTML5 / CSS3 / JS

纯原生技术栈，零框架依赖。HTML5语义化标签提升SEO与可访问性，CSS3实现全部动画与视觉效果，原生JavaScript负责所有业务逻辑与数据交互。

🎨

CSS变量系统

基于CSS自定义属性构建的全局主题系统。通过切换:root与body.light-mode的变量值，实现一键切换深色/浅色两种主题，变量覆盖颜色、阴影、圆角等所有视觉属性。

💾

localStorage持久化

利用浏览器本地存储持久化用户偏好设置（主题选择、最近浏览等）。数据存储在客户端，无需服务器请求，读取速度快，且完全离线可用。

👁️

IntersectionObserver API

利用现代浏览器的交叉观察器API实现高性能的元素可见性检测。用于滚动动画触发、统计数字动画启动和懒加载，避免传统scroll事件监听带来的性能开销。

🎯

Canvas API

利用HTML5 Canvas 2D绘图API实现动态性能对比图表。支持条形图、雷达图和速度曲线对比，所有图表均为代码实时绘制，无需引入任何第三方图表库。

📐

CSS Grid / Flexbox

采用CSS Grid Layout构建二维网格布局（如卡片网格、统计面板），Flexbox处理一维方向排列（如导航栏、列表项）。两者结合实现了灵活且强大的响应式布局系统。

📱

响应式设计

移动优先的响应式设计策略，通过媒体查询、弹性布局和相对单位（rem/vw）确保在320px手机到4K显示器全部设备上获得一致且优雅的浏览体验。

🖼️

SVG图形

使用内联SVG实现品牌Logo图标、装饰元素和UI控件。SVG矢量特性确保在任何分辨率下都清晰锐利，且文件体积小、支持CSS动画和主题色动态变化。
