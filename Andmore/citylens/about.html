🎯 项目简介

CityLens 是一个全球城市生活信息平台，致力于为城市探索者、旅行者和潜在移居者提供全面、数据驱动的城市资料。我们收录了来自全球各大洲的数十个城市数据，涵盖生活指数、居住成本、交通系统、地标建筑等多个维度。

我们的使命是通过透明、开放的城市数据，帮助每个人找到最适合自己的城市——无论是短期旅行、长期移居，还是仅仅满足对世界的好奇心。

📐 城市评分体系

我们对每个城市从以下7个维度进行综合评分，每个维度的权重经过仔细考量，力求全面反映城市生活的方方面面。综合评分 = 各维度得分 x 对应权重的加权平均值。

宜居指数25%

综合评估气候舒适度、空气质量、噪音水平、绿化覆盖率和居民幸福感。

安全指数20%

涵盖犯罪率、政治稳定性、交通安全和自然灾害风险评估。

交通指数15%

评估公共交通覆盖度、拥堵指数、机场连通性和步行友好度。

环境指数12%

度量空气和水质、垃圾处理率、可再生能源使用比例和绿地面积。

教育指数10%

参考高等教育机构数量、国际学校密度、科研产出和识字率。

医疗指数10%

考察医院密度、平均预期寿命、医疗保险覆盖率和医疗服务质量。

生活成本8%

比较租金、餐饮、交通和日常消费的绝对价格和收入比。

所有评分基于公开数据集、政府统计报告和第三方研究机构的数据。评分体系定期审查和校准，确保公平性和准确性。

✨ 功能特色

  • 城市大全——12+城市详细资料和评分
  • 城市详情页——生活指数、地标、气候信息
  • 城市对比系统——参数对比 + 可视化条形图
  • 地图探索——交互式城市分布地图
  • 排行榜——最宜居/最安全/交通最发达/最环保/生活成本排行
  • 地标建筑库——全球著名地标详情弹窗
  • 交通系统——地铁、机场、公交等交通数据
  • 居住成本分析——租金、餐饮、交通等费用对比
  • 城市新闻——瀑布流布局的城市动态
  • 收藏功能——localStorage持久化收藏城市
  • 深色/浅色模式——城市科技风主题切换

🛠️ 技术实现

本项目使用纯原生HTML、CSS和JavaScript构建，未使用任何前端框架。主要技术要点：

  • CSS变量系统实现统一的现代城市科技风主题配色
  • 毛玻璃导航栏（backdrop-filter）
  • 深色/浅色模式切换（localStorage持久化）
  • CSS Grid + Flexbox 响应式布局
  • JavaScript动态数据渲染和筛选分页
  • 城市对比系统的自动优势判断
  • 收藏功能的localStorage存储
  • IntersectionObserver滚动动画触发
  • CSS动画实现霓虹发光、卡片悬浮效果

评分标准由我们的数据分析团队参考国际主流城市评价体系（如全球宜居指数、Mercer生活质量调查）并结合中文用户的实际关注点综合制定。7个评分维度的权重经过多轮调试和用户反馈优化。
在城市卡片或城市详情页中，点击心形图标即可将城市加入收藏。收藏数据保存在您浏览器的localStorage中，不会上传到服务器。换用其他浏览器或清除浏览器数据后收藏会丢失。
