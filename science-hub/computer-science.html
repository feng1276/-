📦 数据结构

📋

数组 Array

连续内存存储，O(1)随机访问，O(n)插入删除。最基础的数据结构。

🔗

链表 Linked List

节点通过指针连接，O(1)插入删除，O(n)随机访问。有单向和双向链表。

📚

栈 Stack

后进先出(LIFO)，用于函数调用、括号匹配、撤销操作等场景。

🚶

队列 Queue

先进先出(FIFO)，用于BFS遍历、任务调度、消息队列等。

🌳

树 Tree

层次化数据结构。二叉搜索树、AVL树、红黑树、B树——各有应用场景。

📊

哈希表 Hash Table

键值对存储，平均O(1)查找。通过哈希函数将键映射到存储位置。

🕸️

图 Graph

由节点和边组成。用于社交网络、地图导航、推荐系统等复杂关系建模。

⛏️

堆 Heap

一种特殊的完全二叉树，用于优先队列、堆排序、Top K问题。大顶堆/小顶堆。
