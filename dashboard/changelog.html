📝 更新日志

WebDash 版本发布记录

v2.3.0 Minor 2024-06-08
  • 新增 知识库模块 — 团队文档管理和在线编辑功能
  • 新增 报告中心 — 支持周度/月度/季度报告自动生成
  • 新增 团队协作页面 — 团队成员展示和组织架构图
  • 优化 仪表板加载性能，首屏渲染时间减少 35%
  • 优化 移动端响应式布局适配
  • 修复 日历视图中跨月事件的显示问题
  • 修复 任务看板拖拽后计数不更新的问题
v2.2.0 Minor 2024-05-22
  • 新增 集成中心 — 第三方服务连接管理（GitHub、Slack、SendGrid）
  • 新增 Webhook 管理 — 支持自定义事件回调
  • 新增 API 密钥管理 — 生成和管理访问令牌
  • 优化 数据分析图表渲染引擎，支持更多图表类型
  • 优化 消息中心搜索性能，支持全文检索
v2.1.0 Minor 2024-05-01
  • 新增 计费管理模块 — 套餐订阅、使用量监控和账单管理
  • 新增 主题设置 — 支持浅色/深色模式和自定义主题色
  • 新增 双因素认证 (2FA) 支持
  • 优化 项目看板 UI，新增项目详情侧边面板
  • 修复 多个浏览器兼容性问题
v2.0.0 Major 2024-04-10
  • 新增 全新仪表板首页 — 数据概览、趋势图表和最近动态
  • 新增 数据分析模块 — 多维度图表、数据表格和自定义筛选
  • 新增 任务管理 — 看板视图、拖拽排序和优先级管理
  • 新增 项目管理 — 项目卡片、进度追踪和里程碑管理
  • 新增 日历排程 — 月视图日历和日程管理
  • 新增 消息中心 — 消息列表、分类筛选和星标功能
  • 优化 全面采用 CSS 变量实现主题系统
  • 优化 侧边栏导航和页面布局统一化
v1.0.0 Major 2024-03-15
  • 发布 WebDash 1.0 — 首个正式版本发布
  • 包含用户认证、仪表板首页和基础设置功能
  • 支持浅色/深色主题切换
  • 响应式布局，适配桌面和平板设备
